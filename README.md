# Calculadora-de-Volume
Programa que calcule o volume de uma caixa retangular

## Sobre o programa
Este programa em Python calcula o volume de uma caixa retangular usando valores fixos para comprimento, largura e altura.  
Ele foi feito de forma simples, com foco na clareza e no aprendizado de conceitos básicos.

## Como funciona
- O programa define as três dimensões da caixa em centímetros.
- Em seguida, calcula o volume multiplicando comprimento, largura e altura.
- Por fim, exibe o resultado na tela já com a unidade correta.
